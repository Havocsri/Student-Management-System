STUDENT MANAGEMENT SYSTEM WITH CLI(COMMENT LINE INTERFACE) USED TO ADD,VIEW,SEARCH,UPDATE,DELETE.

FIRST I SPLIT INTO FOUR FILES :
     [ ] MAIN   -->
     [ ] STUDENT -->
     [ ] STUDENT MANAGER -->
     [ ] FILE HANDLING -->

  1.MAIN :
    THIS THE MAIN CLASS OF PROJECT TO RUN

       INPUT FROM USER WITH SCANNER
       WHILE LOOP
       SWITCH CASE -->CHOICE OF ADD,VIEW,SEARCH,UPDATE,VIEW

  2.STUDENT :
       THIS CLASS STORES THE STUDENT DETAILS --->ID,NAME,AGE,GENDER,DEPARTMENTS,MARKS

       CONSTRUCTOR  -->CONSTRUCTOR IS SPECIALLY CREATING AN OBJECT
       GETTER
       SETTER
       TO-STRING  -->METHODS

 3.STUDENT-MANAGER :
    THE CLASS MANAGE THE STUDENTS DETAILS  --> LOGIC--> WITH PARAMETER

       ADD
       VIEW
       SEARCH
       UPDATE
       DELETE

       ITS USES ARRAYLIST<STUDENT> TO STORE STUDENT OBJECT

 4.FILE-HANDLING
    ITS USED TO SAVE

       CREATE FILE TO SAVE DATA
       READ STUDENT DATA
       THE STUDENT DETAILS STORE IN THIS FILE "students.save"


 5.HOW THE PROJECT WORK

         USER

         MAIN

         STUDENT

         STUDENT-MANAGER

         ARRAYLIST

         FILE-HANDLING

         students.save
